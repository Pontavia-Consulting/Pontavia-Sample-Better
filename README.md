# Fern & Field Garden Co. — Better package sample

A sample website built by **Pontavia Consulting** to show what the **Better ($1,875)** website package includes.
Fern & Field Garden Co. is a made-up business in Ocala, Florida.

Live demo: https://pontavia-consulting.github.io/pontavia-sample-better/
Compare all three packages: https://pontavia-consulting.github.io/pontavia-samples/

A 10-page site for a business that takes bookings and wants to keep its own content fresh. It adds online booking, a filterable plant library, a project gallery, a workshop calendar and Google Business Profile features on top of everything in Good.

## What's included

- Everything in Good
- Up to 10 pages
- Content editor demo: the "Try the owner's editor" button shows how the owner edits text in place
- Online booking: 4-step visit booking with live time slots, photo upload, summary and add-to-calendar file
- Custom forms: workshop seat reservations, "hold this plant" requests
- Google Business Profile features: live open/closed status, hours, map, review rating
- Filterable plant library with search and detail pop-ups
- Project gallery with before/after slider and lightbox
- Plant-of-the-month card that changes with the calendar

## Pages

- `index.html — home with "plant this month" card and live open/closed status`
- `services.html — services and process`
- `design.html — 4-step booking flow`
- `plants.html — filterable plant library`
- `gallery.html — before/after slider and project lightbox`
- `workshops.html — event calendar with seat reservations`
- `team.html — team and story`
- `journal.html — blog`
- `faq.html — questions`
- `contact.html — form, map, live hours`

## Notes

- Plain HTML, CSS and JavaScript. No build step, no framework, nothing to install.
- All plant pictures are SVG illustrations drawn by `assets/art.js`, so there are no stock photos to license.
- This is a front-end demo only: forms, bookings work in the browser but don't send or store anything on a server.
- To preview locally, open `index.html` in a browser, or run `python3 -m http.server` in this folder.
